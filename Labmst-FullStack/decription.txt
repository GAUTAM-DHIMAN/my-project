Introduction – Book Library React App
we have built a **Book Library Management System** using **React with Vite**, designed to help users add, view, and search books efficiently. This app demonstrates a modular component-based architecture, making it scalable and easy to maintain. By organizing your UI into reusable components and integrating them into a central `App.jsx` file, we have laid the foundation for a clean and interactive user experience.
This setup is ideal for learning full-stack development, practicing component communication, and preparing for future enhancements like backend integration or persistent storage.
---
Project Setup
- Initialized a React project using Vite:
  ```bash
  npm create vite@latest labmst-Fullstack
  ```
- Named the project folder: `labmst-Fullstack`.

Folder Structure
- Inside the `src` folder, created a `components` directory to hold all reusable UI components.
- Structure:

  src/
  ├── components/
  │   ├── AddBookForm.jsx
  │   ├── BookItem.jsx
  │   ├── BookList.jsx
  │   ├── LibraryManagement.jsx
  │   └── SearchBar.jsx
  └── App.jsx


Component Roles
- AddBookForm.jsx – Form to input book details and add them to the list.
- BookItem.jsx – Displays individual book information (title, author, etc.).
- BookList.jsx – Renders a list of books using `BookItem`.
- LibraryManagement.jsx – Manages book data, state, and logic.
- SearchBar.jsx – Allows users to search books by title or author.

Integration
- All components are imported into `App.jsx`.
- `App.jsx` acts as the main container, rendering the full UI by combining all components.

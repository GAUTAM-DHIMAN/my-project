💡 Project Title

AI-Powered Chatbot (VORTEX) – Intelligent Conversational Assistant using MERN and Gemini API

🧠 Objective

To design and implement an AI-powered chatbot integrated into a full-stack MERN application, featuring a provider-agnostic Node.js backend capable of communicating with either Google Gemini API or Dialogflow.
The chatbot delivers context-aware, dynamic responses, supports custom prompts, and maintains user-specific conversation history.

⚙️ Tech Stack

Frontend: React.js, TailwindCSS, Framer Motion
Backend: Node.js, Express.js
Database: MongoDB (Mongoose)
AI Model: Google Gemini 2.0 / 2.5 Flash via @google/genai SDK
Environment Management: dotenv
Communication: Axios
Styling: Tailwind CSS (with glassmorphism and gradient themes)
Animation: Framer Motion

🔍 Key Features
💬 Intelligent AI Responses

Utilizes Google Gemini API to generate smart, conversational replies.

Provides predefined fallback responses for common or casual inputs.

🧑‍💻 Message Logging

Stores all user and bot messages in MongoDB for persistent chat history.

Each message includes timestamps, sender details, and session metadata.

⚙️ Provider-Agnostic Backend

Easily switch between Gemini API or Dialogflow without code changes.

🔐 Secure Environment

API keys stored safely using .env files and accessed through process.env.GEMINI_API_KEY.

🌈 Interactive UI (VORTEX)

Clean, responsive chat interface with animated message transitions.

Built using TailwindCSS and Framer Motion for smooth visuals and typing indicators.

Features glassmorphism, gradient buttons, and a pulsing background effect.

⚡ Optimized Response Handling

Displays a “VORTEX is thinking…” placeholder while processing.

Seamlessly replaces it with the generated response once ready.

🧩 Modular Architecture

Organized structure with controllers, routes, models, and React components for scalability.

💾 Session Management

Future-ready for user authentication and context-based conversations.

🚀 How It Works

The user types a query in the VORTEX chat interface.

The message is sent to the backend API endpoint /bot/v1/message.

The server validates the input and logs it into MongoDB.

If no predefined response is found, Gemini API is invoked to generate an intelligent reply.

Both user and bot messages are stored for persistent session history.

The frontend dynamically displays messages with smooth animations.
